## Configure

The connection string is never stored in these projects. Use user secrets or an environment variable:

```
dotnet user-secrets --project src/Invoicing.Api set ConnectionStrings:Hokusai "<connection string>"
dotnet user-secrets --project src/Invoicing.Mcp set ConnectionStrings:Hokusai "<connection string>"
```

Use a least-privilege login for write actions and a read-only login when serving only read actions.
Databases on other machines are refused unless `Hokusai:AllowNonLocalDatabase=true`.

## REST API

```
dotnet run --project src/Invoicing.Api -- hash-key <your-key>     # prints the hash to configure
dotnet user-secrets --project src/Invoicing.Api set Hokusai:Auth:ApiKeyHashes:0 <hash>
dotnet run --project src/Invoicing.Api
```

The API listens on `http://127.0.0.1:5080`, serves its OpenAPI document at `/openapi/v1.json`, and accepts:

- `X-Api-Key: <key>` (or Windows authentication with `Hokusai:Auth:Mode=Windows`),
- `?dryRun=true` to return the planned statements without executing anything,
- `Idempotency-Key: <id>` on write actions so a retried request is not executed twice.

Every call is appended to `audit.jsonl`. The API refuses to start when the schema of any table an action uses
changed since inference.

## MCP server

```
claude mcp add invoicing -- dotnet run --project src/Invoicing.Mcp
```

Read actions run freely. Write actions require `confirm: true`; `dryRun: true` previews the statements.

## Regression tests

```
dotnet test
```

Each recorded demonstration restores its baseline into a fresh database copy (LocalDB for SQL Server sources,
override with `HOKUSAI_TEST_SQLSERVER`), runs the action through the API and compares the row changes with the
app's.
